# Void Launcher (Murzik Edition) 🌑

Минималистичный, быстрый и стильный лаунчер для Android в духе **Void Launcher** / **Olauncher**, созданный для цифрового детокса, отсутствия отвлекающих факторов и мгновенного доступа к нужным приложениям.

---

## ✨ Основные возможности

1. **Главный экран (Home):**
   - **Глубокий чёрный цвет (#000000 AMOLED)** — экономит заряд батареи на OLED-экранах и не утомляет глаза.
   - **Часы и дата** в стиле минимализма (нажатие на часы открывает будильник, на дату — календарь).
   - **Список избранных приложений** (текстом или аккуратным списком).
   - Быстрый переход в поиск и настройки.

2. **Мгновенный поиск (App Drawer):**
   - Свайп вверх с главного экрана мгновенно открывает поиск с клавиатурой.
   - Моментальная фильтрация по первым буквам (русский и английский языки).
   - Нажатие `Enter` / кнопки поиска сразу запускает первое найденное приложение.

3. **Управление приложениями (по долгому нажатию):**
   - **Закрепить / Открепить** на главном экране.
   - **Скрыть приложение** (чтобы не отвлекало).
   - **О приложении** (системные настройки Android).
   - **Удалить приложение** в один клик.

4. **Жесты:**
   - **Свайп вверх** — открыть меню всех приложений с поиском.
   - **Свайп вниз** — открыть шторку уведомлений Android.
   - **Долгое нажатие по экрану** — открыть настройки лаунчера.

5. **Настройки и Приватность:**
   - Переключение между режимом «Только текст» и отображением значков.
   - Раздел «Скрытые приложения» с возможностью восстановить любое приложение.
   - Настройка тактильного отклика (вибрации) и формата времени (12ч / 24ч).
   - Кнопка быстрого перехода в системные настройки для установки лаунчера по умолчанию.

## 📱 Как запустить / установить на телефон

### Способ 1: Через Android Studio (самый простой)
1. Скачайте и установите бесплатную программу [Android Studio](https://developer.android.com/studio) (если ещё не установлена).
2. Запустите Android Studio и выберите **Open** -> выберите папку `Murzik` на рабочем столе.
3. Подключите ваш Android телефон к компьютеру по USB-кабелю (включите на телефоне режим «Отладка по USB» в меню разработчика).
4. Вверху в Android Studio выберите ваш телефон и нажмите зеленую кнопку **Run ▶**.
5. Лаунчер сразу установится и запустится на вашем телефоне!

---

### Способ 2: Собрать файл `.apk` и перекинуть на телефон
1. В Android Studio перейдите в верхнем меню: **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
2. После сборки появится уведомление с кнопкой **locate**.
3. Файл `app-debug.apk` можно просто скинуть себе в **Telegram**, **WhatsApp** или через провод на телефон и нажать **«Установить»**.

---

### Как сделать его главным лаунчером на телефоне:
После установки:
1. Откройте приложение **Void Launcher**.
2. Зайдите в **Настройки** (иконка шестерёнки внизу справа).
3. Нажмите **«Сделать лаунчером по умолчанию»** и выберите Void Launcher.
